# FORM / FACTOR
### Один объект. Шесть ракурсов. Одна визуальная история.

**Тип проекта:** концептуальный интерактивный сайт / 3D product experience  
**Формат:** desktop + mobile  
**Год:** 2026  
**Демо:** https://port1-drab-seven.vercel.app/  
**Исходный код:** https://github.com/tanyazar-hash/port1

> FORM / FACTOR — независимый концепт продуктового сайта. Это демонстрация визуального дизайна и фронтенд-разработки, а не официальный сайт производителя устройства.

## 01 / Обложка

**Главный заголовок:** ФОРМА, КОТОРАЯ ВПЕЧАТЛЯЕТ.

**Подзаголовок:** Интерактивная 3D-презентация смартфона, в которой прокрутка становится инструментом исследования объекта.

**Визуал для обложки:** крупный скриншот первой сцены на ПК. Для карточки проекта — кадр без интерфейса браузера, с телефоном справа и типографикой слева.

**Короткая подпись для портфолио:** Product design · 3D interaction · Creative development

## 02 / Задача

Обычная карточка товара показывает фотографии, характеристики и набор преимуществ. В FORM / FACTOR задача другая: превратить просмотр одного объекта в последовательный визуальный опыт, не перегружая экран интерфейсом.

**Цели проекта:**
- Сфокусировать внимание на форме и материалах устройства.
- Сделать прокрутку частью презентации: каждый новый экран раскрывает другой ракурс.
- Сохранить ощущение премиального минимализма.
- Обеспечить удобный просмотр на компьютере и смартфоне.

## 03 / Концепция

**Шесть глав — один объект.** Камера последовательно показывает устройство спереди, сбоку, сзади и вблизи, а текст дополняет визуальный рассказ.

Прокрутка не просто меняет блоки: она плавно поворачивает и масштабирует 3D-модель. В результате пользователь исследует форму объекта, а не листает отдельные статичные изображения.

**Ключевая идея:** меньше интерфейса — больше внимания к объекту.

## 04 / Визуальный язык

**Палитра:** холодные серебристые поверхности, светло-серые градиенты, графитовые заголовки, металлические блики.

**Типографика:** Manrope для выразительных заголовков и основного текста; DM Sans для технических подписей.

**Композиция:** на ПК — редакционная колонка текста и крупный объект в свободном пространстве. На мобильных устройствах — вертикальная композиция: модель сверху, текст ниже.

**Детали:** тонкие линии, нумерация глав, небольшие поясняющие подписи и аккуратная навигация по шести сценам.

## 05 / Шесть сцен

| Глава | Содержание | Кадр для кейса |
| --- | --- | --- |
| 01 — Первое впечатление | Общий вид, силуэт и главный заголовок | Desktop hero |
| 02 — Горизонтальная грань | Толщина и точность металлического контура | Edge detail |
| 03 — Материалы | Задняя панель, отражения и фактура | Rear view |
| 04 — Вертикальная грань | Профиль корпуса и геометрия | Side profile |
| 05 — Камеры | Крупный план блока объективов | Camera macro |
| 06 — Финал | Возвращение к цельному образу | Closing scene |

**Для публикации:** достаточно четырёх сильных десктопных кадров (01, 03, 04, 05), одного мобильного коллажа и короткого видео прокрутки. Все шесть сцен можно показать в виде компактной ленты.

## 06 / 3D и анимация

3D-модель в формате GLB загружается в Three.js через React Three Fiber. Для каждой главы задан ракурс, а при прокрутке положение, вращение и масштаб плавно интерполируются.

Технические особенности:
- Непрерывная анимация одной модели вместо переключения между шестью картинками.
- Подсветка материалов и изменение освещения во время движения.
- Появление текстовых блоков при входе в сцену.
- Привязка подписей к положению 3D-объекта.
- Поддержка системной настройки уменьшения анимации.

**Визуал:** короткий ролик 10–20 секунд с переходами между главами 01 → 03 → 04 → 05 → 06.

## 07 / Адаптация под мобильные устройства

Мобильная версия не копирует десктоп в уменьшенном виде. Для узких экранов композиция перестраивается: объект занимает верхнюю часть экрана, а текст получает собственную зону чтения.

Масштаб модели рассчитывается по доступной области 3D-сцены и габаритам повёрнутого объекта. Это позволяет использовать общую адаптивную логику вместо отдельных настроек под каждую модель телефона.

**Визуал:** три вертикальных кадра рядом — первый экран, профиль и камеры. Желательно показывать чистые скриншоты без адресной строки браузера.

## 08 / Реализация

**Стек:** React · TypeScript · Vite · Three.js · React Three Fiber · Drei · CSS · Playwright.

- Компонентная структура интерфейса.
- Управление 3D-сценой на основе прокрутки.
- Адаптивные стили и контроль положения объекта.
- E2E-проверки основных экранов и мобильной компоновки.
- Размещение проекта через GitHub и Vercel.

## 09 / Результат

FORM / FACTOR демонстрирует, как объединить визуальную концепцию, анимационную режиссуру и работающий адаптивный интерфейс в одном проекте.

**Что показывает этот кейс потенциальному заказчику:** способность разработать необычную концепцию, собрать интерактивный сайт с 3D, продумать мобильную версию и довести реализацию до публичного демо.
